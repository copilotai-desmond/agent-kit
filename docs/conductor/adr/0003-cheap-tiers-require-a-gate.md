# A delegate runs below strong-code only behind a gate

The "no degradation" guarantee comes from verification, not model choice. A role may run on mechanical or bulk-read only when a gate can prove its output. A gate failure escalates one tier with the failure attached, never a second try at the same tier. Verifiers come from a different model family where the binding offers one. The orchestrator never drops below the session's model, and conductor never switches the session model.
